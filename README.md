# MSFriends

为低版本 Minecraft 添加好友系统的多平台模组，支持 Fabric、NeoForge 和 Forge。

## 功能

- 好友列表管理
- 在线状态显示
- P2P 连接（基于 WebRTC）
- 跨平台支持（Fabric / NeoForge / Forge）

## 构建要求

- Java 25
- Gradle 8+

## 构建

```bash
./gradlew build
```

构建产物将输出到 `out/` 目录。
